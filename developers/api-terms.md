# API terms of use

*Last updated: October 14, 2026*

These terms apply when you use the LinkMC API, including the profile, server, skin, embed,
and plugin endpoints, and **Sign in with LinkMC**. They add to the
[Terms of service](terms.md). By using the API, you agree to these terms and to the
[API code of conduct](api-conduct.md).

## Access

- The API is free to use for personal projects, bots, mods, websites, and tools.
- You don't need an API key. If you create one, keep it secret, and don't share it with
  other developers.
- LinkMC can change, limit, or stop the API, or any endpoint, at any time. LinkMC tries to
  announce breaking changes in advance on the News page.

## Attribution

If you show LinkMC data in a public product, credit LinkMC with a link to
`https://linkmc.app`, such as "Powered by LinkMC". For details, see
[Branding and attribution](branding.md).

## Data from the API

- Use player data only for the purpose that your users expect, such as showing a profile or
  checking an account in your community.
- Don't build a copy of LinkMC's database, and don't keep player data longer than you need
  it. When a player removes something from their LinkMC profile, stop showing it within
  24 hours.
- Data that you get through **Sign in with LinkMC** may only be used for the purposes that
  the player approved. You're responsible for protecting it and for following the privacy
  laws that apply to you.
- Don't sell, rent, or resell API data or access to the API.

## Restrictions

You may not use the API to:

- Build a competing Minecraft identity or account-verification service.
- Impersonate LinkMC or suggest that LinkMC endorses your product.
- Track, profile, or harass players.
- Get around rate limits, blocks, or other limits.

## Commercial use

Commercial projects can use the API under these terms. If you expect heavy traffic, contact
LinkMC first.
